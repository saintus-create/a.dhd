# Managed Care's Guide - Content Source

Edit the `.mdx` files in this folder to update the website.

## Files

| File | Page |
|------|------|
| `index.mdx` | Overview (home page) |
| `safety-data.mdx` | FDA FAERS Safety Data |
| `studies.mdx` | All 105 Research Studies |
| `prescribing-context.mdx` | LDX Prodrug, HAP Data, Step Therapy |
| `about.mdx` | About This Guide |
| `contact.mdx` | Contact |
| `meta.json` | Sidebar order and title |

## How to edit

1. Click any `.mdx` file above
2. Click the pencil (Edit) icon on GitHub
3. Make your changes -- it's plain Markdown
4. Click **Commit changes**

**Important:** After editing, the site needs to be rebuilt and redeployed from Replit to go live.
